# MAREA — web escaparate

Web estática de una sola página para MAREA. No incluye carrito ni pagos.

## Archivos
- `index.html` — estructura de la web.
- `style.css` — diseño.
- `script.js` — filtros, menú móvil y animaciones.
- `products.js` — catálogo de productos.
- `images/` — carpeta preparada para tus imágenes.

## Para cambiar productos
Abre `products.js` y modifica los nombres, precios, descripciones e imágenes.

## Para cambiar WhatsApp e Instagram
En `index.html`, busca:
- `https://wa.me/34600000000`
- `https://instagram.com/marea.jewelry`

y sustitúyelos por tus datos reales.

## Publicación
La web está preparada para GitHub Pages, Netlify o Vercel. No necesita servidor ni base de datos.
